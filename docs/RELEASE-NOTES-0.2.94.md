# DiPlay v0.2.94 — 三指下滑快捷面板双栏卡片重构、解码退避降负载与焦点防黑屏优化

## 更新

- **投屏内三指下滑快捷设置面板双栏卡片式重构**：
  - 彻底重新设计三指下滑快捷面板：改为更适合车载横屏的左右双栏卡片布局（左侧快捷分类导航 + 右侧独立设置卡片）。
  - 支持高对比度触控反馈，操作更直观顺手；修复了投屏会话中实时更改车标图标后未即时同步更新到界面的问题。
- **老旧车机解码队列智能退避与音量调节防黑屏优化**：
  - 针对全志 T3、MTK 8227L 等老旧车机，优化视频解码队列拥塞时的自适应退避时间，避免空转死循环挤占 CPU 算力。
  - 移除了此前失去窗口焦点时直接撤除视频 Surface 的激进逻辑，彻底解决在部分车机上调节系统音量、下拉通知栏或浮窗弹窗时导致的画面闪黑、卡死问题。
- **有线拔插卡死看门狗清理与外置蓝牙死流复用修复**：
  - 增强有线拔插看门狗超时机制，确保在物理拔线或控制器卡死时安全回收全部底层管道端点。
  - 修复外置 USB 蓝牙适配器在重新发起配对时复用陈旧 RFCOMM 通道导致的死流断连故障。
