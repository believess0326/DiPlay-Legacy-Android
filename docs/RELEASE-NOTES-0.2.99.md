# DiPlay v0.2.99 — 麦克风24kHz采样率重采样回退、自定义车标握手超时根治、SoftAVC与地图解码器防崩溃加固

## 更新

- **老旧车机麦克风硬件不支持 24kHz 采样率报错与重采样平滑回退**（Issue #329）：
  - 针对部分老旧 Android 车机硬件仅支持 16kHz/44.1kHz/48kHz 采样率、在 AudioRecord 初始化请求 24kHz 时抛出错误代码 `code=-2`（STATE_UNINITIALIZED）导致 Siri 语音输入完全无声的问题；
  - 在 `MicrophoneUplink` 中加入硬件可用采样率探测与轻量级软件重采样回退机制：当 24kHz 初始化失败时，自动回退到车机原生支持的采样率并实时高质量重采样为 24kHz，确保语音输入稳定可用。
- **自定义汽车品牌车标导致 RTSP 握手超时根治**（Issue #328）：
  - 修复用户导入自定义车标图片后，在无线 CarPlay 初始引导阶段导致 RTSP SETUP 握手超时、CarPlay 频繁断连的问题；
  - 优化品牌图标元数据序列化与缓存加载时机，杜绝在主连接关键路径上进行大图同步 IO 与重编码阻塞。
- **软件解码器（SoftAVC）底层 `-2` 崩溃与地图流频繁重建死锁消除**（Issue #324, #326, #327）：
  - 解决部分机型在启用或回退到系统软件解码器（`OMX.google.h264.decoder`）时底层返回 `-2` 导致的画面崩溃问题；
  - 彻底优化高德地图等导航应用在动态切流场景下的解码器生命周期管理，避免高频重建触发老旧系统驱动死锁。
- **SurfaceView 画面四周黑边消除与视口重对齐优化**（Issue #290）：
  - 进一步完善倒车退出及多窗口分屏恢复时的视口尺寸计算，彻底消除各种分辨率比例下可能残留的像素黑边。
- **无线 CarPlay 引导握手与 USB 蓝牙自启强化**（Issue #316, #321）：
  - 进一步加固了无线连接初始协商的容错策略与外置蓝牙适配器无感启动。
- **Root hostapd 车载热点与 MapEmbedService 安全加固**：
  - hostapd SSID/密码严格过滤控制字符与换行符，防止命令注入风险，并在退出时彻底清理临时配置文件与租约状态；
  - MapEmbedService 强化调用权限校验，限制仅桌面启动器及系统授权组件可连接附着。
