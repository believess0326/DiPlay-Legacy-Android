# DiPlay v0.3.7 — 修复倒车高度变化Surface重挂启动崩溃、独立通话音量提升与下行免通信模式

## 更新

- **修复 Android 5.1.1 启动尺寸震荡 SurfaceView 重新挂载空指针崩溃**（Issue #290）：
  - 修复倒车退出及启动尺寸震荡（如 1024x600 -> 1024x500 -> 1024x600）期间同步移除并重新添加 SurfaceView 导致后续布局遍历解引用未就绪窗口崩溃（NPE）的致命缺陷；
  - 将回退 SurfaceView 的重新挂载排队至当前布局遍历之后异步执行（`fallback.post`），并在回调中严密二次校验 View 与父容器状态，彻底解决启动必崩问题。
- **解耦通话音量提升与通信模式，覆盖麦克风兼容模式**（Issue #290）：
  - 将 `STREAM_VOICE_CALL` 音量提升至最大并在通话结束后还原的逻辑独立为幂等方法 `boostCallStreamVolume()`；
  - 即使车机开启麦克风兼容模式（跳过 `enterCommunicationMode`），依然能够正常提升并还原通话音量。
- **通话下行走媒体流实验下跳过通信模式避免固件通道劫持**（Issue #343）：
  - 当启用“通话下行走媒体流”实验性选项时，完全跳过进入 `MODE_IN_COMMUNICATION` 通信模式，防止特定车机固件因切换通信模式接管音频路由而导致原本已写入媒体流的下行声音被静音。
