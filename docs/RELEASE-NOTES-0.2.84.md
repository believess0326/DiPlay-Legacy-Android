# DiPlay v0.2.84 — 有线 NCM bulk-out 状态字探针与接口重置恢复

## 更新

- **有线 NCM 传输故障探针与自动重选恢复（#279）**：
  - 针对部分定制车机 USB 控制器在 bulk-out 发送失败时仅返回 `-1`、难以区分设备 STALL 还是主机端队列楔死的问题，在首次连续失败时主动通过标准 `GET_STATUS` 请求读取 OUT 端点状态字（检测 halt 位）并输出诊断日志。
  - 在连续发送失败达到 5 次时，自动执行与打开链路相同的 `SET_INTERFACE` 重选数据接口（同步复位双方的数据触发位 Data Toggle）并再次清除 halt 状态，成败结果及端点状态同步写入日志；发送恢复后自动复位计数，避免稳态收发引入额外开销。
