# DiPlay v0.2.81

## 更新

- 新增车机蓝牙音频旁路开关（#261）：通过 iPhone 与车辆已有的蓝牙连接播放音频；检测到外置 USB 蓝牙缺少 A2DP 能力时显示确认提示。
- 新增通话麦克风兼容模式：针对部分全志 T3、定制 ROM 使用标准 MIC 输入，优化静音检测，并在持续全零数据时记忆兼容回退，用于改善微信及电话通话上行无声。
- 视频解密移至独立工作线程，并在收包时绑定 Nonce 序号（#249），修复队列丢帧造成的解密计数错位和后续认证失败。
- 倒车影像回切、TextureView 重建后主动请求画面刷新（#250）。
- 增加 USBMUX 接口声明退避重试，适应 USB 配置切换后内核释放较慢的车机（#256）。
- 改善后台或设置页无法显示外置 USB 蓝牙配对弹窗时的配对处理。
- 增加有线 mDNS 诊断计数（#262），分别记录应答调用、已匹配查询、发送或入队、丢弃帧及未匹配查询，便于定位连接中断环节。

## 验证

- 版本：`0.2.81`，`versionCode 101`；包名 `com.shihab.diplay`；最低 Android 4.2（API 17）。
- 本次构建、签名、自动化测试与 Android 4.4 模拟器验证结果将在发布前填入。
- 实体全志 T3 车机、绿联 CM390、iPhone 的实际配对、通话、倒车切换及 CarPlay 连接效果仍需实机验证；模拟器测试不替代这些验证。
