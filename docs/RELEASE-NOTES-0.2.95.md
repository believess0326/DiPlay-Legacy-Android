# DiPlay v0.2.95 — 复杂画面解码平滑自愈、倒车黑屏恢复、USB弹窗死锁修复与导航焦点保活

## 更新

- **地图等复杂高码率画面解码平滑追帧与防卡死优化**（Issue #310 / #314）：
  - 彻底解耦“瞬态排队积压”与“解码器硬件故障”：进入高德地图等大尺寸密集帧时，若处理稍慢触发积压，仅丢弃旧帧并请求 IDR 关键帧，**不再粗暴销毁重建解码器**。
  - 将单帧积压容忍窗口由 250ms 放宽至 800ms，彻底终结低配老车机在地图界面陷入 0.2fps、触控延迟 36s 的恶性卡死死循环。
- **倒车影像退出后黑屏不恢复缺陷修复与画面卡死自愈**：
  - 修复倒车影像切回 CarPlay 时因 Surface 尺寸重置时序导致的画面黑屏不恢复缺陷。
  - 增强低帧率和空帧管线卡死自愈机制，确保倒车后立即恢复流畅投屏显示。
- **全志 T3 系统 USB 弹窗拦截消除与内核自旋锁死锁修复**（Issue #311）：
  - 移除 Manifest 中 `CarPlayHostActivity` 的静态 `USB_DEVICE_ATTACHED` intent-filter，彻底消除插入 iPhone 时弹出的系统级“要用 DiPlay 打开吗”对话框抢占与双重枚举冲突。
  - 在底层枚举探针中针对 Android 4.x / API <= 19 加入 150ms 硬件退避延时，彻底根除老旧 Linux 3.4 `sw_usb` 驱动导致的 D-state 自旋锁死锁、系统看门狗复位及 RTC 时钟重置。
- **音乐与导航并发时高德播报失声缺陷修复**（Issue #310）：
  - 完善 `AudioFocusCoordinator` 音频焦点多通道追踪，导航与通话通道在媒体播放期间保持活跃记录。
  - 后台释放检查时若有导航正在活跃，禁止释放音频焦点租约，彻底防止老旧车机原厂硬件功放被切断静音。
