# DiPlay v0.2.91 — hostapd 配置文件暂存安全部署、自定义车标保存期硬约束与伪版本车机诊断容错

## 更新

- **Root hostapd 配置文件暂存安全部署（#301, #306）**：
  - 针对本田思域等部分改装车机或第三方精简 ROM 中底层 shell 对 heredoc 语法支持缺陷导致配置文件为空的问题，改用应用私有空间生成后阶段文件复制（staged file copy）到运行目录。
  - 彻底规避 shell 截断，保障 hostapd 与 dnsmasq 守护进程稳定拉起，解决热点启动失败问题。
- **自定义车标图片保存期硬约束（512px / 256KB）（#263）**：
  - 在用户选取并保存车标时，直接在保存阶段强制执行最大 512 像素和 256 KB 体积限制。
  - 提前完成采样解码与压缩，杜绝过大车标拖垮 AirPlay 会话协商数据或引发内存抖动，保障仪表盘车标渲染精致稳定。
- **篡改/伪版本（fake-version）车机诊断导出保护（#300）**：
  - 针对将 Android 4.4 伪造为 Android 10/11 的后装车机 ROM，次级音量扫描前增加底层真实 API 级别门控，避免调用高版本独有系统服务引起 Crash，确保诊断报告在任意篡改 ROM 上均可完整导出。
- **有线 NCM 链路诊断 NTB OUT 参数偏移纠正（#307）**：
  - 修正 NCM 链路诊断探测中读取 NTB OUT 参数结构体的偏移量，确保底层 USB 有线网络协商状态与传输快照记录准确无误。
