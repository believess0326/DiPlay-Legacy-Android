# DiPlay v0.2.83 — 有线直连 usbfs 模式、拔插与无线稳定性加固

## 更新

- **有线 USB 直连 usbfs 模式（#266）**：针对部分定制固件 Android 框架层 USB 主机服务失效（`UsbManager.getDeviceList()` 恒为空）导致无法识别 iPhone 的车机，新增通过 sysfs 直接枚举、直通 `/dev/bus/usb` 原始节点及 root 授权兜底；有线链路支持整体切入直连模式（高级设置中提供开关与 9 步详细日志诊断）。
- **有线快速拔插与重连状态机加固（#275 / #270 / #243）**：
  - 完整会话后拔出重插时主动触发一次厂商重枚举，避免 iPhone 维持旧链路状态导致 `syn=0`。
  - 低版本车机在有线链路多次无 TCP 握手失败后，自动停止无意义的无限重试，并在界面清晰提示用户手动拔插 iPhone 恢复连接。
  - 统计并诊断上一会话旧 `dataPort` 的残留 TCP 流量与未匹配 mDNS 查询名，杜绝旧端口数据淹没新会话控制流。
- **通话 Opus 音频解码容灾降级（#272）**：针对硬件 Opus 解码器创建失败导致通话无声的问题，自动回退到纯软件解码并在音频流内实时重试，保障通话双向声音正常输出。
- **外置 USB 蓝牙（CM390/CM591 等）握手与重连优化（#274）**：
  - 在复用缓存的 RFCOMM 链路前自动检测并淘汰已关闭的死流，防止蓝牙快速重连失败。
  - 当 iOS 拒绝 L2CAP SDP 查询或超时时，自动回退默认 iAP2 通道 1 继续建链；容忍低版本系统内核关闭套接字时 reader 线程的延迟退出。
- **跨平台与低版本兼容性加固**：
  - 适配各种 Android 系统及 Robolectric 模拟环境下的 `UsbInterface` 私有构造差异，支持动态端点绑定。
  - 无线启动失败时在诊断停止行补充具体失败详情文本，便于用户导出报告排查。
