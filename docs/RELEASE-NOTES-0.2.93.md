# DiPlay v0.2.93 — 无线会话邀请持续重传与 hostapd ifconfig 双格式自适应

## 更新

- **持续重传无线会话邀请直至 TCP 连通（#293）**：
  - 针对 iPhone 在弱网、切网延迟或后台休眠时未能第一时间建立连接的情况，优化控制通道握手机制。
  - 在传输层网络就绪通知发出后，保持以安全周期持续重传会话邀请，直至双方 TCP 正式建链成功，彻底解决无线连接偶发卡在等待界面的握手超时问题。
- **兼容 hostapd ifconfig 双格式输出与设置错误显性化（#308）**：
  - 完美兼容不同车机系统自带工具箱（busybox / toybox / toolbox）输出的 `inet addr:` 和 `inet ` 两种不同的 ifconfig 文本格式。
  - 在为热点网卡接口分配静态 IP 失败时，直接在诊断与错误流中暴露具体执行结果与退出码，彻底消除静默失败，保障本田思域等改装车机实验性 Root 热点的可靠启动与排障。
