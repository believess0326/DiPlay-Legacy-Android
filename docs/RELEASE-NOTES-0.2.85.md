# DiPlay v0.2.85 — 全志 T3 有线拔插防死锁、原生软件 Opus 通话解码与媒体/导航独立音量

## 更新

- **有线连接与低版本车机稳定性（#286 / #275 / #269 / #256）**：
  - 修复全志 T3（Android 4.4.2）等低版本车机在拔插 iPhone 重连时停在“正在打开 USB 数据通道”导致整机卡死无响应的问题；重枚举门闩调整为进程级并消除重复探测瞬态冲击，延长 usbfs 底层释放延时至 400ms，中止连接时跳过对已失效句柄的持锁等待。
  - 在 USBMUX 认领遭遇 ENOENT 时自动重选配置并重新尝试一轮，提升 USB 链路建立容错率。
- **通话与音频增强（#272 / #253 / #263）**：
  - 针对缺失系统硬件 Opus 解码器的旧版 Android ROM，集成内置 `libopus` 原生软件解码回退，彻底解决通话全程无声的问题。
  - 新增媒体与导航独立音量偏好设置，音频渲染器支持按不同音频流独立调节数字增益。
- **无线热点与蓝牙连接加固（#271 / #281）**：
  - 手动热点模式下自动开启失败不再硬挡连接，由手动热点管理器自行通过真实接口确认网络就绪，兼容长安奔奔 E-Star 等热点运行在框架外的定制系统。
  - 修复蓝牙残留 ACL 导致 L2CAP 0x4 无限拒绝的死循环，引入强制断链恢复机制与探测日志去重。
  - 会话清理引入 3 秒单项资源超时保护，防止单个底层连接卡死堵死整个 teardown 过程。
- **画面与触控优化（#216 / #251 / #282 / #283）**：
  - 等待关键帧超时超 5 秒自动升级为全量恢复请求；窗口焦点恢复时主动刷新画面；直角开关补齐视频层容器处理；触控按下记录缩放坐标供竖屏映射。
- **在线更新器兼容性修复**：
  - 客户端全面兼容带 UTF-8 BOM 的 SHA-256 校验和文本，杜绝在线下载更新时报校验文件无效。
