# DiPlay v0.3.3 — 无线连接稳定性增强：多次失败后提示修复、IPv6 地址等待限流、显示面回退修复及诊断增强

## 更新

- **无线 CarPlay 连续失败4次后弹出忘记并修复提示**（Issue #290）：
  - 新增 `WirelessLinkFailurePrompt` 逻辑，当连续链路失败达4次时自动弹出对话框，引导用户忘记车机热点并重新配对，消除因热点 IP 漂移或密钥过期导致的持续无法连接困境。
- **无线 CarPlay 限制 IPv6 地址等待时间，IPv4 可用后快速进入**（Issue #343）：
  - 修复 IPv4 地址已分配时仍等待 IPv6 地址最多整个超时周期的问题；
  - 一旦 IPv4 可用，将 IPv6 额外等待时间上限压缩至短暂宽限期（数百毫秒），大幅缩短热点建立延迟。
- **修复倒车退出后显示面回退时高度增长导致 surface 无法恢复**（Issue #290）：
  - 强制在 reverse-return 阶段检测到倒车退出高度增长时触发 fallback surface 重建，消除因 surface 高度异常增长后 CarPlay 画面黑屏/冻结的问题。
- **热点启动失败时捕获 hostapd 启动证据**（Issue #337）：
  - 在 hostapd 热点启动失败时自动收集并保存启动日志证据，写入诊断报告，便于在无 root 的车机上定位热点失败根因。
- **音频统计中记录 PCM 峰值**（Issue #309）：
  - 在音频统计日志中增加每个缓冲区的 PCM 峰值（dBFS），配合音频闪避诊断，帮助排查车机音量异常与静音问题。
- **诊断 USB 报告导出时执行 best-effort 同步**（Issue #341）：
  - USB 报告文件复制完成后执行尽力同步（`fsync`），减少在低端车机文件系统上文件写入不完整导致诊断包损坏的概率。
