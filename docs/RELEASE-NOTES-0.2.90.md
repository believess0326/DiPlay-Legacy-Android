# DiPlay v0.2.90 — hostapd 多路径探测、超大车标安全采样与外置蓝牙权限诊断加固

## 更新

- **Root hostapd / dnsmasq 多路径动态探测（#301）**：
  - 针对本田思域等改装车机或部分第三方精简 ROM，不再硬编码二进制位于 `/system/bin`。
  - 运行时动态探测 `/system/bin`、`/system/xbin`、`/vendor/bin` 等候选路径，彻底解决底层守护程序缺失报错导致实验性车载热点启用失败的问题。
- **自定义大尺寸车标图标安全采样下采样（#263）**：
  - 对用户导入的大尺寸高清车标图片，先通过 `inSampleSize` 采样解码降低内存开销，再缩减载荷封入 AirPlay 会话数据，避免协议数据超限或 OOM，确保仪表盘与车机车标高清显示。
- **外置 USB 蓝牙 Dongle 权限申请全流程诊断（#291）**：
  - 针对部分定制车机（如 RTL8761B 等芯片）点击“授予USB权限”无响应的现象，增加权限申请全生命周期日志（Intent 构造、系统分发、授权结果），便于定位车机 Framework 拦截原因。
- **有线 NCM 链路状态诊断兼容路由（#137）**：
  - 将 NCM 链路状态诊断通过受版本保护的 alternate-setting 辅助类安全路由，保障在 API 17-19 等老旧车机上诊断逻辑平稳执行。
- **多窗口分屏与倒车影像防抢占（#300）**：
  - 倒车挡覆盖或分屏切换时主动让出视频 Surface，杜绝分屏下画面闪烁透出与图层冲突。
