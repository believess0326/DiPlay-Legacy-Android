# DiPlay v0.2.89 — 原生 ChaCha20-Poly1305 屏幕帧解密加速、Root hostapd 热点后端与音频焦点优化

## 更新

- **原生 ChaCha20-Poly1305 屏幕帧解密加速（#249）**：
  - 针对全志 T3、掌讯 AC8317、MTK 等低性能老款车机，新增轻量级纯 C 实现的原生 ChaCha20-Poly1305 解密模块与 JNI 桥接。
  - 屏幕视频帧解密摆脱纯 Java / BouncyCastle 层的开销与内存拷贝，大幅降低 CPU 负载并改善高帧率下的画面卡顿与发热。
- **实验性 Root hostapd 车载热点后端（#294, #299）**：
  - 在“高级设置”中新增可选的 Root 权限 hostapd 热点管理后端。
  - 专为定制 ROM 或被厂商精简了原生车载热点 API 的车机提供备选支持，可直接调用底层 hostapd 守护进程开启热点。
- **音频焦点租约与系统通道优化**：
  - 不再在 `STREAM_MUSIC` 媒体流上保持永久性音频焦点占用，释放对车机本地收音机与原生播放器的独占。
  - 焦点归还逻辑严格隔离：仅在媒体通道释放时归还租约，确保导航打断恢复更加平滑。
- **Android 4.2/4.3（API 17-18）底层兼容性加固**：
  - 严格清理源码 catch 块中高版本系统异常类型引用（避免在低版本 Dalvik 虚拟机上触发类校验与 NoClassDefFoundError 崩溃）。
- **多窗口分屏优化与投屏显示体验修复（#300）**：
  - 多窗口/分屏状态下让出视频 Surface：当其他窗口获得屏幕所有权或应用失去焦点时，主动让出视频 Surface 释放图层占用，杜绝分屏或画中画切换时的黑屏与图层冲突。
  - 有线 bulk-OUT 传输异常时上报 errno 与 NCM 链路状态，改善 USB 物理拔插链路诊断能力。
  - 修正有线连接达到超时上限后的启动重试状态流转。
  - 日间模式下 CarPlay 等待界面保持舒适暗色底色，避免白屏刺眼；调整显示缩放前预先持久化，保障重连无缝生效。
- **安全加固与配置清理**：
  - 移除了构建配置中硬编码的私钥回退口令；远程 MFi 仅限局域网访问；非导出 BootReceiver 避免外部意外部署唤醒。
