# DiPlay v0.2.87 — 开机冷启动车载热点 60s 宽裕预算、会话关闭时晚到 iAP2 消息丢弃与投屏快捷设置菜单自绘样式统一

## 更新

- **开机冷启动车载热点就绪预算（慢车机优化）**：
  - 在全志 T3 等启动缓慢的车机平台上，系统或第三方车载热点 AP 服务初始化常常显著滞后于 DiPlay 开机自启；以往每阶段仅 15 秒预算，导致前几次尝试频繁因“车载热点网络未就绪”报废掉全部 5 次重试机会。
  - 现在若开机（Boot）3 分钟内发起连接，自动开启与接口状态观察阶段各自赋予 60 秒的充裕就绪预算，让开机自启连接能够从容等待车载 AP 就绪，彻底解决开机启动后停留在热点错误界面的问题。
- **会话断开拆链稳定性（#292）**：
  - 会话断开或 teardown 期间，上层消费端已退出，队列中残留的晚到 iAP2 控制消息可能触发队列溢出限流，导致本应干净的正常拆链被错误记为 CSM 失败（teardown completed=false）。
  - 在链路与 CSM 通道开始关闭后，直接丢弃晚到的控制消息，确保拆链流程平稳完成，消除多余的错误日志与非预期状态残留。
- **投屏内快捷设置菜单视觉重构与旧版系统兼容**：
  - 将三指划出的投屏快捷菜单从过去的独立绿色主题全面统一至主设置界面的卡片风格（CARD 调色板与圆角卡片布局）。
  - 针对 API 19 / 20 等低版本 Android 系统缺少控件着色（tint list）支持的问题，采用自绘 StateListDrawable 渲染单选框、开关与滑块游标，并在输入框与按钮上采用圆角填充背景，在老车机上获得与主设置一致的高质感视觉体验。
