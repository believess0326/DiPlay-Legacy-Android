# DiPlay v0.2.88 — P2P 保留组重用、有线 bulk-OUT 看门狗、关键帧防抖与大众/丰田车标银白色重构

## 更新

- **无线 P2P 组保留与频段自适应（#293）**：
  - 支持复用已有客户端的保留 P2P 组（retained P2P group），显著减少断开重连时的建组耗时。
  - 单频 2.4 GHz 硬件自动跳过 5 GHz 频段建组尝试，杜绝硬件不支持引起的等待与重试。
  - 在首个 TCP 连接握手超时后，自动向 iPhone 宣告备选地址族（IPv4 / IPv6 自动切换），提高弱网和复杂信道下的无线连接成功率。
- **有线 USB bulk-OUT 传输看门狗（#137）**：
  - 针对全志 T3 等老旧车机 USB 控制器在突发大数据传输时可能出现 bulk-OUT 挂起永不返回的硬件缺陷，引入传输看门狗超时机制。
  - 超时自动安全回收管道端点，彻底解决拔插或高负荷投屏下有线连接卡死的问题。
- **视频解码容错与布局重构防抖（#251, #288, #290）**：
  - 关键帧等待恢复逻辑加入防抖机制，杜绝偶发网络抖动时反复重启解码器引起的剧烈卡顿。
  - 上游丢帧主动通知硬解码器处理参考帧缺失，减少画面花屏。
  - Surface 销毁重建与倒车后视退出后，采用两阶段安全重新适配（two-stage reapply）计算视频贴合边界，防止黑屏与形变。
- **蓝牙 Dongle 记忆与诊断日志完善（#272, #281, #289）**：
  - 准确持久化记录 USB 蓝牙 Dongle 的开启选择并在拔插后正确恢复。
  - 诊断日志结构化输出回声消除（AEC）实际运行指标（活动状态、参考流与尾音延迟）。
  - 容错保护剪贴板导出与空 ARP 状态，诊断导出即使在部分构建异常时也能完整保留日志。
- **车标优化与 AirPlay 会话保护**：
  - 大众（Volkswagen）和丰田（Toyota）车机车标重着色为银白色，提升深色与浅色车机仪表盘下的对比度与精致度。
  - 限制会话协商中自定义车标图标体积上限，避免过大图标导致协议栈协商异常。
