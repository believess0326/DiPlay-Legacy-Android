# DiPlay v0.3.0 — 华为海思硬件原生端口解码、倒车退出延时冷启防死锁、开机热点自愈广播及诊断更新加固

## 更新

- **华为海思（HiSilicon K3）硬件 AVC 解码器原生端口尺寸兼容**（Issue #324）：
  - 彻底解决 Android 4.4.2 系统软解仅支持 Baseline profile（不支持 Main/High CABAC 流导致 `-2` 永久黑屏）的问题；
  - 明确触发 `ACodec CHECK(def.nBufferSize >= size)` 的根因在于 `KEY_MAX_INPUT_SIZE` 强行覆盖了底层 OMX 组件的原生端口缓冲；将海思 K3 硬件解码器调整为原生端口尺寸（Untuned 格式，不强制设置 `KEY_MAX_INPUT_SIZE` 与 `KEY_PRIORITY`），恢复纯硬件满血稳定解码。
- **掌讯/MTK 老旧芯片倒车退出延时冷启防死锁（实验性）**（Issue #315）：
  - 针对 MTK 8227L 等老旧车机在倒车退出切回瞬间导航帧积压冲击导致驱动死锁的问题，在「高级设置 → 实验性显示」中新增「倒车退出延时冷启」开关；
  - 挂入倒挡时彻底释放主视频解码器并切断输入队列；退出倒挡时等待 2.5 秒让系统倒车图层与 Surface 稳定，随后冷启动解码器并请求最新 IDR 关键帧出图。
- **开机原厂车载热点自愈广播**（Issue #315）：
  - 针对部分车机（如掌讯 PF8227）开机后系统从不自动启动热点、导致手机无热点可连的问题，在 `BootReceiver` 中新增自愈机制；在收到 `BOOT_COMPLETED` 广播且用户启用了热点自启时，后台线程自动触发开启原厂热点，无需手动进入系统设置。
- **老旧车机诊断导出兼容与内置更新镜像超时优化**（Issue #332, #333）：
  - 修复伪装 Android 4.4（底层实为 4.2）车机在导出诊断报告时缺少存储目录接口引发的 `NoSuchMethodError`，平滑回退安全导出；
  - 优化应用内置更新客户端的镜像回退逻辑与超时友好提示。
- **局域网 Existing Wi-Fi 多 IP 通告与老旧车机蓝牙栈自动复位**（Issue #330）：
  - 修复多网卡环境下现有局域网 Wi-Fi 模式多 IP 冲突通告；
  - 增强老旧车机在异常状态下的蓝牙底层栈自动复位能力，避免手动重启。
