# DiPlay v0.2.86 — 视频解密槽位背压防丢帧、日产/奥迪车标浅色优化与有线重枚举状态持久化

## 更新

- **视频流解密与播放稳定性（#288）**：
  - 在慢解密硬件平台（如软件解密性能受限的低算力车机芯片），当解密队列满时采用最多 120ms 的槽位等待与背压机制代替直接丢帧；通过降低 TCP 接收端速率驱动 iPhone 自适应降速，避免瞬间尖刺丢帧破坏 H.264 参考帧链，彻底消除满屏马赛克与黑屏 0fps 现象。
- **品牌车标视觉优化（#263）**：
  - 重新调整 Nissan（日产）与 Audi（奥迪）的品牌图标样式，改为高辨识度的银白色线条与现代品牌视觉，彻底解决在 CarPlay 深色图标底板上车标全黑沉底、形同黑块的问题。
- **有线连接重连稳定性加固（#269）**：
  - 将「已完成会话」状态标记调整为 SharedPreferences 持久化存储；即便会话成功后应用进程被车机系统后台杀掉，新拉起的进程在重新插拔与重连时仍能有效判断强制重枚举逻辑，防止重连陷入控制通道超时或 iPhone 不建立 TCP 的死锁循环。
- **无线手动热点就绪预算独立化（#284）**：
  - 手动热点就绪观察阶段采用独立完整的就绪预算时间，不再与自动开启共用同一份 15 秒截止时间，大幅提高长安 CS75 Plus 等特定车机上反复报告热点未就绪、需要耗时 90 秒以上重试的握手成功率与速度。
- **通话麦克风诊断与异常保护（#272）**：
  - 通话麦克风启动时规范化输出回声消除三要素（AEC 设置、兼容模式、回声参考），便于精细化排查回声与杂音根因；增加保护机制确保诊断回调的异常不会阻断麦克风启动。
